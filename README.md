# PredIL6

# Introduction
We have developed PredIL6, a cutting-edge ensemble learning model that accurately identifies Interleukin-6(IL-6)-inducing peptides by stacking the probability scores generated by 148 single-feature machine learning and deep learning models, using a genetic algorithm-based meta-classifier.
